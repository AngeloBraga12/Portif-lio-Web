# DevTrack

Dashboard responsivo construído para demonstrar desenvolvimento front-end moderno com React e TypeScript.

## O que demonstra

- React com hooks e gerenciamento de estado.
- TypeScript com tipagem das respostas da API.
- Consumo paralelo da API pública do GitHub com `Promise.all`.
- Estados de carregamento, sucesso e erro.
- Busca por usuário do GitHub.
- Interface responsiva para desktop e mobile.
- Links externos seguros.
- Build com Vite.

## Stack

React · TypeScript · Vite · CSS · GitHub REST API · Lucide React

## Executar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Objetivo

Projeto de portfólio criado para demonstrar integração com API REST, tratamento de estados, tipagem, responsividade e organização de uma aplicação front-end moderna.
