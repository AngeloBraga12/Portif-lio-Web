## Projetos

### DevTrack

Dashboard responsivo desenvolvido com React + TypeScript para consulta de perfis e repositórios públicos do GitHub.

Demonstra consumo de API REST, tipagem, hooks, gerenciamento de estado, estados de loading/erro/sucesso, `Promise.all` e interface responsiva.

Diretório: [`/devtrack`](./devtrack)

### Portfólio pessoal

Site responsivo desenvolvido com HTML, CSS e JavaScript, com tema claro/escuro, navegação entre seções, filtro de projetos e formulário de contato com validação no navegador.

### Barbearia

Projeto de interface web utilizando Sass e integração para contato via WhatsApp.

### Hambúrgueria

Site responsivo desenvolvido com Tailwind CSS, com foco em apresentação de produtos e experiência simples para o usuário.
